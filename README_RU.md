# FPV Drone 0.1.40

Расходуемый FPV-дрон для Fallout 4: запуск броском мины, переход через Pip-Boy
к камере дрона, ручной полёт и подрыв. Поддерживаются клавиатура/мышь,
XInput-геймпады и DirectInput-пульты в USB-режиме джойстика.

[English](README.md) · [Сборка](BUILDING.md) · [Проверка и отчёт об ошибке](TESTING.md)

## Требования

- Fallout 4 **1.10.163**, Windows x64. Next-Gen и VR не поддерживаются; DLC не нужны.
- [F4SE 0.6.23](https://f4se.silverlock.org/), включая его скрипты.
- [Garden of Eden Papyrus Script Extender 23.4+](https://www.nexusmods.com/fallout4/mods/74160), основной пакет с DLL и скриптами. Legacy 19.7 не подходит.
- [Mod Configuration Menu 1.39 для Old-Gen](https://www.nexusmods.com/fallout4/mods/21497) — для выбора и настройки контроллера. Без MCM доступны клавиатура/мышь со стандартной чувствительностью.

Зависимости устанавливаются отдельно. Address Library, HUDFramework, FallUI и MCM Helper основному моду не требуются.

## Установка и запуск

Основной архив релиза: `FPVDrone-0.1.40.zip`. Он содержит готовый мод;
исходный код на GitHub не нужно устанавливать в `Data` целиком.

1. Закрой Fallout 4 и установи архив основного мода через MO2 или Vortex. Для ручной установки помести его содержимое в `Data`.
2. Включи `FPVDrone.esp` и запускай игру через F4SE; с MO2 — через список запуска MO2.
3. На химверстаке в категории «Мины» создай **FPV Drone** и выбери его как гранату.
4. Удержи и отпусти обычную кнопку гранаты. Последовательность: бросок → поднятие Pip-Boy → затемнение → FPV.

На время открытия Pip-Boy включается первое лицо. После полёта или отмены
возвращаются исходная камера и управление. Один завершённый бросок расходует
один дрон; потраченный предмет не возвращается при отмене после выпуска,
потере сигнала или завершении полёта.

Рецепт: алюминий ×3, проводка ×2, медь ×2, клей ×1, удобрение ×2, масло ×1.
Перк не требуется.

## Управление

| Ввод | Действие |
| --- | --- |
| Штатная кнопка гранаты | Запуск выбранного дрона |
| W / S | Увеличить / уменьшить газ |
| A / D | Рысканье |
| Мышь | Крен и тангаж |
| ЛКМ | Подрыв |
| F10 | Отмена без взрыва |

W/S сохраняют достигнутый газ. Автовыравнивания нет. HUD показывает скорость,
газ, отметку висения, сигнал и расстояние. Чувствительность меняется в MCM.

### Геймпад и FPV-пульт

1. Подключи устройство и открой **MCM → FPV Drone → Устройство управления полётом**.
2. Обнови список и выбери устройство. Выбор относится к полёту дрона;
   остальная игра может использовать другой способ управления.
3. Для Xbox/XInput или DualShock 4 выбери автоматическую раскладку. Для
   другого USB-пульта выбери ручную и настрой оси, инверсию, мёртвую зону и кнопки.
4. По умолчанию газ следует положению стика: вниз — 0%, центр — 50%, вверх — 100%.
   Старый режим изменения газа доступен отдельно. Настройки применяются к следующему полёту.

В раскладке Mode 2 левый стик управляет газом/рысканьем, правый — креном/тангажом.
Кнопки в MCM нумеруются с 1; 0 отключает действие. По умолчанию Xbox A — подрыв,
B — отмена. F10 остаётся аварийной отменой. В режиме контроллера ЛКМ не подрывает дрон.

Пульт должен определяться Windows как XInput или DirectInput-джойстик.
Мод не заменяет отсутствующее выбранное устройство другим; отключение пульта
во время полёта завершает полёт без взрыва. Подключение после загрузки игры поддерживается.

## Ограничения

Запуск подтверждён в основной и лёгкой сборках. В основной сборке также
подтверждён запуск при глобальном управлении Fallout 4 геймпадом. Совместимость со всеми
модами камеры, Pip-Boy, анимаций, мебелью и силовой бронёй не проверена.
Оператор и дрон используют общую область загрузки мира; потеря сигнала завершает полёт.

Экспериментальный 3D-viewmodel вынесен в отдельный архив
`FPVDrone-Viewmodel-0.1.40-experimental.zip`, который устанавливается поверх
основного мода. Рендеринг runtime 4 ещё требует проверки в игре. Основной архив
не включает `FPVDroneViewmodel.dll` и `drone_fpv.nif` и работает без дополнения.

## Если есть только бросок без Pip-Boy

Убедись, что выбран расходуемый `FPVDroneWeapon` — FormID `xx00080E`.
`xx000807` — служебный `FPVDroneLaunchProp`: название и минная анимация совпадают,
но этот предмет не запускает FPV. `xx` зависит от порядка загрузки.
Крафт на химверстаке выдаёт правильный предмет.

Диагностика: **MCM → Diagnostics** или `cqf FPVDroneQuest Diagnose`.
Аварийный возврат: `cqf FPVDroneQuest AbortFlight`.
Журналы и данные для отчёта перечислены в [TESTING.md](TESTING.md).

Для удаления: заверши полёт, выполни `cqf FPVDroneQuest Shutdown`, сохранись,
закрой игру и отключи мод. Для повторного включения в этом сохранении:
`cqf FPVDroneQuest EnableMod`.
